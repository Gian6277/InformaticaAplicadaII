Sección 01

Página vs. sitio web

Estos dos términos suelen confundirse, pero tienen un significado técnico distinto:

Página web

Un único documento HTML, con su propia URL, que se puede visitar de forma independiente (ej. la página "Contacto").

Sitio web

El conjunto de páginas relacionadas entre sí, conectadas por hiperenlaces y alojadas bajo el mismo dominio (ej. todo "miempresa.com": Inicio, Productos, Contacto, Blog).

💡 Analogía

Si el sitio web es un edificio, cada página es una habitación. El menú de navegación es como el pasillo que conecta las habitaciones entre sí.

Sección 02

Estructura de una página: header, body y footer

Casi cualquier página web sigue una estructura similar en tres grandes bloques:

Bloque Contenido habitual Función
Header (encabezado)Logo, menú de navegación, buscadorIdentidad y acceso rápido a las secciones
Body (cuerpo)Contenido principal de la páginaEl mensaje central que se quiere comunicar
Footer (pie)Datos de contacto, redes sociales, enlaces legalesInformación secundaria de referencia
💡 Consistencia

El header y el footer suelen repetirse idénticos en todas las páginas de un sitio, para que la persona nunca pierda la orientación al navegar entre secciones.

Sección 03

Menú de navegación y jerarquía de contenidos

El menú de navegación es el mapa que le muestra a la persona qué secciones tiene el sitio y cómo moverse entre ellas.

  • Navegación primaria: las secciones más importantes, siempre visibles (Inicio, Productos, Nosotros, Contacto)
  • Navegación secundaria: subsecciones dentro de una categoría (ej. dentro de "Productos": Ropa, Calzado, Accesorios)
  • Migas de pan (breadcrumbs): el camino recorrido dentro del sitio (Inicio > Productos > Calzado)
✅ Regla de las 3 secciones

Como referencia general, un menú principal claro no debería superar unas 5 a 7 opciones. Demasiadas opciones en el menú confunden más de lo que ayudan.

Sección 04

Elementos visuales de una página

Hero o banner principal

La primera imagen o sección grande que se ve al entrar a una página, pensada para captar la atención inmediatamente.

Llamada a la acción (CTA)

Un botón o enlace destacado que invita a realizar una acción concreta: "Comprar ahora", "Contactanos", "Suscribirse". Es uno de los elementos más importantes en Marketing.

Formularios

Campos donde la persona ingresa datos (nombre, email, mensaje) para contactar a la empresa o suscribirse a novedades.

Sección 05

Mapa del sitio (sitemap)

El sitemap es un esquema (visual o técnico) que muestra todas las páginas de un sitio y cómo se relacionan entre sí. Es el primer paso al planificar cualquier sitio nuevo, antes de diseñar una sola página.

💡 Dos tipos de sitemap

El sitemap visual sirve para planificar la estructura con el cliente antes de construir el sitio. El sitemap XML es un archivo técnico que ayuda a los buscadores a indexar todas las páginas del sitio correctamente.
