Sección 01

¿Qué es Internet?

Internet es una red mundial de computadoras conectadas entre sí, capaces de intercambiar información siguiendo reglas comunes (protocolos). La Web (World Wide Web) es solo una de las formas de usar Internet: el sistema de páginas y sitios que navegamos con un navegador.

Para el Marketing, entender cómo funciona Internet por debajo es clave para tomar mejores decisiones: desde elegir un nombre de dominio hasta entender por qué un sitio aparece (o no) en los buscadores.

💡 Internet vs. Web

Internet es la infraestructura (los cables, servidores y conexiones). La Web, el correo electrónico y las apps son distintos "servicios" que funcionan sobre esa infraestructura.

Sección 02

La URL: anatomía de una dirección web

La URL (Uniform Resource Locator) es la dirección que identifica un recurso específico en la Web. Se puede descomponer en partes:

Parte Ejemplo Qué indica
Protocolohttps://Cómo se transmite la información (de forma segura o no)
Dominiomiempresa.comEl "nombre" identificable del sitio
Subdominiotienda.miempresa.comUna sección separada dentro del mismo dominio
Ruta (path)/productos/zapatillasLa ubicación específica dentro del sitio
Parámetros?color=azul&talle=42Datos adicionales que modifican lo que se muestra
💡 HTTPS

La "S" de HTTPS significa que la conexión está cifrada (segura). Hoy es un estándar mínimo esperado, y su ausencia genera desconfianza y penaliza el posicionamiento en buscadores.

Sección 03

La IP y los servidores

Dirección IP

Es el número único que identifica a cada dispositivo conectado a Internet (ej. 192.168.1.1). Los dominios (como google.com) existen para que las personas no tengan que memorizar estos números.

DNS (Sistema de Nombres de Dominio)

Es el "directorio telefónico" de Internet: traduce el nombre de dominio que escribimos a la dirección IP real del servidor donde está alojado el sitio.

Servidor y hosting

El servidor es la computadora donde "vive" físicamente un sitio web, siempre encendida y conectada a Internet. El hosting es el servicio que alquila espacio en esos servidores para alojar un sitio.

Sección 04

Hiperenlaces

El hiperenlace (o link) es lo que conecta una página con otra, y es el elemento que le da a la Web su forma de "red". Sin hiperenlaces, cada página sería una isla aislada.

  • Enlaces internos: conectan páginas dentro del mismo sitio web
  • Enlaces externos: conectan hacia otros sitios web
  • Enlaces entrantes (backlinks): enlaces desde otros sitios que apuntan hacia el propio
✅ En Marketing

La cantidad y calidad de enlaces entrantes que recibe un sitio es uno de los factores que los buscadores usan para decidir qué tan confiable y relevante es ese sitio.

Sección 05

Buscadores y PageRank

Un buscador (Google, Bing) es un sistema que rastrea, indexa y ordena las páginas de Internet para responder a las búsquedas de las personas.

Rastreo e indexación

El buscador envía "robots" (crawlers) que recorren la Web siguiendo hiperenlaces, y guardan una copia organizada del contenido de cada página en su índice.

PageRank

El algoritmo original de Google para ordenar resultados, que asigna más relevancia a las páginas que reciben enlaces desde otras páginas ya consideradas importantes. Sentó las bases de cómo funcionan los buscadores modernos.

💡 SEO

El conjunto de técnicas para mejorar la posición de un sitio en los resultados de búsqueda se llama SEO (Search Engine Optimization), y es uno de los pilares del Marketing digital.

Desarmar una URL

Cómo posiciona Google
